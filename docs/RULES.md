# Правила валідатора

Згенеровано командою `python -m lpnu_docx_validator list-rules --markdown`.
Рівень кожного правила змінюється в секції `severities` конфігу або на вкладці «Правила» в GUI.
Цілу групу вмикають/вимикають у секції `checks`.

| Правило | Група | За замовчуванням | Опис |
| --- | --- | --- | --- |
| `page_setup` | Сторінка й поля | ERROR | Формат сторінки, орієнтація або поля. Порівнює розмір аркуша й поля кожної Word-секції з налаштуваннями. |
| `page_number_missing` | Нумерація сторінок | WARNING | Немає номера сторінки. У потрібному колонтитулі не знайдено поле PAGE. |
| `page_number_alignment` | Нумерація сторінок | ERROR | Номер сторінки не там. Номер є, але вирівняний не так, як вимагається. |
| `page_number_section_start` | Нумерація сторінок | ERROR | Нумерація починається не зі змісту. Секція з номерами сторінок починається раніше за ЗМІСТ. |
| `page_number_first_page` | Нумерація сторінок | WARNING | Номер прихований на першій сторінці секції. Увімкнено «Особливий колонтитул для першої сторінки», і в ньому немає номера. |
| `structure_missing` | Структура роботи | ERROR | Немає обов'язкової частини. Наприклад, ВСТУП чи ВИСНОВКИ. |
| `structure_order` | Структура роботи | WARNING | Порушено порядок частин роботи |
| `structure_main_start` | Структура роботи | WARNING | Не знайдено початок основної частини. Без цього титульна частина може потрапити в перевірки. |
| `toc_manual` | Структура роботи | WARNING | Зміст набрано вручну. Немає автоматичного змісту Word (поле TOC). |
| `toc_outdated` | Структура роботи | WARNING | Зміст не відповідає заголовкам. Зміст треба оновити (F9) або виправити заголовки. |
| `toc_forbidden_entry` | Структура роботи | WARNING | У змісті є зайвий пункт. Наприклад, індивідуальне завдання (див. structure.toc_forbidden_patterns). |
| `paragraph_alignment` | Основний текст | WARNING | Вирівнювання абзацу |
| `paragraph_indent` | Основний текст | WARNING | Абзацний відступ |
| `paragraph_line_spacing` | Основний текст | WARNING | Міжрядковий інтервал |
| `paragraph_spacing` | Основний текст | WARNING | Інтервал перед/після абзацу |
| `paragraph_font` | Основний текст | WARNING | Шрифт основного тексту |
| `paragraph_font_size` | Основний текст | WARNING | Розмір шрифту основного тексту |
| `empty_paragraphs` | Порожні абзаци | WARNING | Кілька порожніх абзаців підряд |
| `heading_number_dot` | Заголовки | ERROR | Крапка після номера розділу/підрозділу. «1.1. Назва» замість «1.1 Назва». |
| `heading_trailing_dot` | Заголовки | WARNING | Крапка в кінці заголовка |
| `heading_section_case` | Заголовки | WARNING | Назва розділу не великими літерами |
| `heading_subsection_case` | Заголовки | WARNING | Регістр назви підрозділу |
| `heading_bold` | Заголовки | WARNING | Заголовок розділу не напівжирний |
| `heading_alignment` | Заголовки | WARNING | Вирівнювання заголовка |
| `section_new_page` | Заголовки | WARNING | Розділ не з нової сторінки. Перед заголовком розділу немає розриву сторінки/секції чи «з нової сторінки». |
| `heading_numbering_sequence` | Нумерація заголовків і об'єктів | WARNING | Пропуск у нумерації підрозділів. Наприклад, після 1.2 іде 1.4. |
| `caption_numbering_sequence` | Нумерація заголовків і об'єктів | WARNING | Пропуск у нумерації рисунків/таблиць |
| `caption_chapter_mismatch` | Нумерація заголовків і об'єктів | WARNING | Номер рисунка/таблиці не відповідає розділу. Рис. 2.1 розміщено в розділі 1. |
| `caption_missing` | Рисунки, таблиці, підписи | ERROR | Немає підпису рисунка/таблиці |
| `caption_position` | Рисунки, таблиці, підписи | ERROR | Підпис не на своєму місці. Рисунок — підпис знизу, таблиця — підпис зверху. |
| `caption_alignment` | Рисунки, таблиці, підписи | ERROR | Вирівнювання підпису |
| `caption_duplicate` | Рисунки, таблиці, підписи | ERROR | Дубльований номер рисунка/таблиці |
| `caption_trailing_dot` | Рисунки, таблиці, підписи | WARNING | Крапка в кінці підпису |
| `caption_format` | Рисунки, таблиці, підписи | WARNING | Підпис не за зразком «Рис. 1.1 — Назва». Наприклад, «Рис 1.1 Назва»: без крапки після «Рис» або без тире між номером і назвою. |
| `object_reference_missing` | Рисунки, таблиці, підписи | ERROR | Немає згадки рисунка/таблиці до його появи |
| `section_empty` | Завершення підрозділів | ERROR | Підрозділ без тексту |
| `section_ends_with_object` | Завершення підрозділів | ERROR | Підрозділ закінчується рисунком/таблицею |
| `formula_number_missing` | Формули | WARNING | Формула без номера |
| `formula_reference_missing` | Формули | WARNING | Немає згадки формули в тексті |
| `table_font_size` | Таблиці | WARNING | Недозволений розмір шрифту в таблиці |
| `appendix_invalid_letter` | Додатки | ERROR | Недозволена літера додатка |
| `appendix_sequence` | Додатки | WARNING | Порушено послідовність літер додатків |
| `appendix_not_referenced` | Додатки | WARNING | Немає згадки додатка в тексті |
| `bibliography_missing` | Список джерел | ERROR | Немає списку джерел |
| `bibliography_empty` | Список джерел | ERROR | Список джерел порожній |
| `source_number_missing` | Список джерел | ERROR | Джерело без номера |
| `source_sequence` | Список джерел | WARNING | Порушено нумерацію джерел |
| `source_bare_url` | Список джерел | ERROR | Джерело — голе посилання без опису |
| `source_too_short` | Список джерел | WARNING | Надто короткий опис джерела |
| `source_missing_year` | Список джерел | WARNING | Немає року видання |
| `source_missing_access_date` | Список джерел | WARNING | Немає дати звернення до електронного ресурсу |
| `source_missing_url` | Список джерел | WARNING | «URL/Режим доступу» без самого посилання |
| `source_article_pages` | Список джерел | WARNING | Немає сторінок статті («С. 10–15») |
| `source_refs_missing_all` | Посилання на джерела | ERROR | У тексті немає жодного посилання на джерела |
| `source_ref_unknown_number` | Посилання на джерела | ERROR | Посилання на неіснуюче джерело |
| `source_missing_in_text` | Посилання на джерела | ERROR | Джерело не згадано в тексті |
| `source_ref_suspicious` | Посилання на джерела | WARNING | Нерозпізнане посилання в квадратних дужках |
| `source_ref_order` | Посилання на джерела | OFF | Джерела не в порядку першої згадки. Вмикайте, якщо список має бути впорядкований за появою посилань у тексті (а не за абеткою). |
| `double_space` | Типографіка | WARNING | Кілька пробілів підряд |
| `space_before_punctuation` | Типографіка | WARNING | Пробіл перед розділовим знаком |
| `hyphen_instead_of_dash` | Типографіка | INFO | Дефіс замість тире. « - » між словами замість « — » або « – ». |
| `straight_quotes` | Типографіка | INFO | Прямі лапки "…" замість «…» |
| `mixed_script` | Типографіка | WARNING | Латинські літери всередині кириличних слів. Часто це помилка розкладки, але так само обходять перевірку на плагіат. |
| `leading_spaces` | Типографіка | WARNING | Відступ пробілами або табуляцією. Абзацний відступ має задаватися в параметрах абзацу. |
| `manual_line_break` | Типографіка | INFO | Розрив рядка (Shift+Enter) в абзаці |
| `tracked_changes` | Залишки редагування | WARNING | Невиконані виправлення (режим рецензування) |
| `comments_present` | Залишки редагування | INFO | У документі є примітки |
| `hidden_text` | Залишки редагування | WARNING | Прихований текст |
| `colored_text` | Залишки редагування | INFO | Кольоровий текст в основній частині |
| `highlighted_text` | Залишки редагування | WARNING | Виділений маркером текст |
| `image_too_wide` | Зображення | WARNING | Зображення ширше за поле тексту |
| `image_low_resolution` | Зображення | INFO | Низька роздільна здатність зображення |
| `page_count_out_of_range` | Обсяг роботи | ERROR | Обсяг роботи поза нормою |
| `page_count_unknown` | Обсяг роботи | INFO | Не вдалося порахувати сторінки |
